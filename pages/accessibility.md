# Accessibility Statement

This site was built by Anh for DH 101.

I have tried to make it accessible by:

* Adding alt text to all images so they can be understood by screen readers
* Ensuring sufficient color contrast between text and background
* Using descriptive link text instead of vague phrases like "click here"
* Organizing content clearly for easier navigation

If you encounter any barriers, please contact me at [trinh_a2@denison.edu](mailto:trinh_a2@denison.edu).
